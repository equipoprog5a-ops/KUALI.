# KUALI - Página promocional

## Estructura
- `index.html` — página completa con HTML, CSS y JavaScript.
- `assets/kuali-mockup.jpeg` — imagen proporcionada como referencia/preview.

## Para usarla
1. Abre `index.html` en tu navegador.
2. Para publicar en GitHub Pages, sube `index.html` y la carpeta `assets`.
3. En el botón "Próximamente" sustituye `href="#"` por el enlace real de descarga de KUALI.

## Personalización
Los colores principales están definidos al principio del CSS:
- `--navy`
- `--orange`
- `--blue`
- `--sky`

También puedes reemplazar la imagen de `assets/kuali-mockup.jpeg` por capturas individuales de la aplicación.
